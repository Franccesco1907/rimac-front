# RIMAC frontend

React, TypeScript and Vite insurance-plan selection app with Redux state.

Run `npm ci`, then `npm run dev`. Plan and user fixtures are fetched from the URLs in `src/plans/pages/PlanPage.tsx`; internet access is required.
Checks: `npm run build` and `npm run lint`. No automated test script is configured.
The Pages workflow builds and publishes only pushes to `main` (or manual runs).
